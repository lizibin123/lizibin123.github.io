关于工作室

杭州萧山莫门软件开发工作室（Momentum Studio）是一家专注软件定制开发的技术工作室，2026 年注册于杭州市萧山区。我们的核心理念很简单：用代码解决实际问题，不画饼，把东西做出来。

创始人李子彬，计算机科班出身，拥有从 Java 后端到 Python 全栈的丰富实战经验。曾任职于大型企业后端开发团队，也在量化交易领域深度耕耘——独立搭建了运行中的 A 股全自动交易系统（夏普比率 2.39，年化收益 55%）。现在全职投入莫门工作室，为个人和企业提供靠谱的软件定制服务。
