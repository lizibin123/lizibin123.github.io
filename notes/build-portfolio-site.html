从零搭建个人作品集网站的完整记录

2025 年 5 月 · 约 4 分钟阅读

这篇文章记录了莫门工作室官网从零到上线的全过程，包括设计思路、技术选型和实现细节。

为什么要自己搭网站

作为独立开发者，作品集网站就是你的名片。用第三方平台（如 Notion、知乎）虽然方便，但不够自由——你不能完全控制展示方式，也不能加入自己的风格。

自己搭一个网站，成本其实比想象中低。不需要服务器，不需要域名，纯静态页面就能做得很好看。

技术选型

  • 纯 HTML + CSS + JS — 没有框架依赖，加载快，部署简单
  • 深色主题 — 视觉统一，对作品展示友好
  • CSS 动画 — 动态光源背景和滚动淡入效果提升体验
  • Node.js — 用于需求接收服务（可选）
选型原则：能用浏览器原生 API 解决的问题，就不用第三方库。这样网站加载快、易维护、部署灵活。

页面结构

  • Hero — 首屏印象，三个核心按钮导航
  • 关于 — 个人介绍 + 技能标签
  • 作品集 — 项目卡片，点进去有详情页
  • 笔记 — 文章列表，支持独立阅读页
  • 联系 — 联系方式 + 需求表单

部署方式

目前是本地访问。后续可以部署到 GitHub Pages，完全免费，一行命令就能搞定：

cd 个人官网
git init
git add .
git commit -m "init"
# 推送到 GitHub 仓库后开启 Pages 即可

一点感想

自己动手搭网站的过程本身就是一个作品。从设计到开发到上线，每一步都能体现你的能力和品味。不要觉得「完美的网站」才能上线，先搭起来，再慢慢优化。
