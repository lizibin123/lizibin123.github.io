QuantGrid 开发复盘：我给 A 股写了个网格回测工具

2026 年 5 月 · 约 4 分钟阅读

前段时间花了两天时间写了一个 A 股网格交易回测工具——QuantGrid。这篇文章复盘一下从想法到落地的全过程和踩的坑。

为什么做这个

我自己做网格交易有几个月了，但一直没找到好用的回测工具。市面上要么收费，要么太复杂。就想自己写一个：输入股票代码和网格参数，能快速看到历史表现就行。

说白了就是一个需求驱动的小工具，够用就好。

技术选型

  • Python 3 — 数据分析和回测的首选语言
  • Pandas — 数据处理，核心计算全靠它
  • Matplotlib — 出图表，直观看收益曲线
  • Akshare — 免费获取 A 股历史行情数据
  • NumPy — 数值计算辅助
数据来源：Akshare 是一个开源的 A 股数据接口库，免费、无需注册，直接 pip install 就能用。数据质量够回测用。

网格策略核心逻辑

网格交易的核心思想很简单：设定一个价格区间，把资金分成若干份，每跌一格买入、每涨一格卖出。反复赚取波段差价。

QuantGrid 的实现流程：

1. 获取历史行情数据（日 K）
2. 设定网格参数（层数、间距、初始资金）
3. 逐日模拟交易
   → 价格跌破网格线 → 买入
   → 价格涨破网格线 → 卖出
4. 计算最终收益、最大回撤、交易次数
5. 画出资金曲线图

关键代码片段

网格模拟的核心逻辑大概 30 行：

def grid_backtest(df, grid_levels, grid_spacing, initial_capital):
    capital = initial_capital
    holdings = 0
    per_grid = capital / grid_levels
    history = []

    for price in df['close']:
        for level in range(grid_levels):
            buy_price = initial_price * (1 - (level+1) * grid_spacing)
            sell_price = initial_price * (1 + (level+1) * grid_spacing)

            if price <= buy_price and capital >= per_grid:
                holdings += per_grid / price
                capital -= per_grid

            elif price >= sell_price and holdings > 0:
                sell_units = holdings / grid_levels
                capital += sell_units * price
                holdings -= sell_units

        portfolio_value = capital + holdings * price
        history.append(portfolio_value)

    return history

踩坑记录

  • 除零错误 — 初始价格为 0 的时候没做判断，翻车了。加了个 if initial_price == 0: continue
  • 数据漂移 — 前复权和后复权的数据差异很大。回测统一用前复权，策略参数才不会失真
  • 手续费 — 一开始没算印花税和佣金，回测收益率虚高。后来加了个可配置的费率参数

回测结果示例

用某 ETF 近 3 年数据回测，2 层网格、间距 3%、起始资金 10 万：

总收益率:   +12.3%
年化收益率:  +3.9%
最大回撤:   -5.1%
交易次数:   47 次

同期沪深 300 涨幅约 -8%，网格策略在震荡市中确实有效。但在单边牛市中会踏空，单边熊市中会满仓套牢。没有完美的策略，只有适合当前市场的策略。

开源与后续

QuantGrid 已经开源在 GitHub：github.com/lizibin123/QuantGrid。后续打算加入多标的回测和参数优化功能。

量化交易入门门槛其实不高，Python + Pandas 能解决 80% 的问题。写回测工具本身也是很好的编程练习，推荐大家试试。
