独立开发者如何用 GitHub Pages 搭建个人品牌网站

2026 年 5 月 · 约 5 分钟阅读

作为独立开发者，你的名字就是品牌。而个人网站就是品牌的核心载体——它比任何第三方平台都更可控、更持久。

这篇文章分享我用 GitHub Pages 搭建莫门工作室官网的全流程和心得。

为什么选 GitHub Pages

  • 免费 — 带宽和托管都不要钱，没有服务器费用
  • 自动化 — 推代码即部署，git push 完等两分钟就上线
  • 自定义域名 — 可以绑自己的域名，看起来专业
  • 纯静态 — 速度极快，几乎不会被攻击
一句话总结：GitHub Pages = 免费托管 + 自动部署 + 自定义域名。独立开发者起步的首选。

搭建流程

第一步：创建仓库

在 GitHub 创建一个名为 你的用户名.github.io 的仓库。比如我的就是 lizibin123.github.io。

这个仓库的名字是固定的，GitHub 会自动识别并为它开启 Pages 服务。

第二步：本地开发

和开发普通网站一样，写 HTML / CSS / JS：

个人官网/
├── index.html          # 首页
├── assets/
│   ├── style.css       # 全局样式
│   └── main.js         # JS 交互
├── portfolio/          # 作品集详情页
├── notes/              # 技术笔记
└── team/               # 开发团队

不需要框架，不需要构建工具，纯手写反而加载更快、更可控。

第三步：部署上线

cd 个人官网
git init
git add .
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/用户名/用户名.github.io.git
git push -u origin main

推送完成后，去 GitHub 仓库 Settings → Pages，确认 Source 选的是 main 分支。等 1-2 分钟，你的网站就上线了。

设计要点

  • 深色主题 — 省电、护眼、看着高级。当前主流设计趋势
  • 一个主色调 — 我选了青色 #64ffda，所有交互元素都围绕它展开
  • 减少动效 — 几个关键的淡入和悬浮效果就够了，不要过度动画
  • 移动端适配 — 现在 60% 的流量来自手机，响应式是必须的

自定义域名

如果你想绑自己的域名，三步搞定：

1. 在域名管理后台加一条 CNAME 记录
   名称: @  或  www
   目标: 你的用户名.github.io

2. 在仓库根目录创建 CNAME 文件
   内容是：你的域名（如 yongle.dev）

3. 在 GitHub Pages 设置里填上自定义域名

等 DNS 生效（一般几分钟到几小时），就可以用自己的域名访问了。

加访问统计

推荐用 不蒜子（busuanzi.ibruce.info），一行代码搞定：

<script async src="//busuanzi.ibruce.info/busuanzi/2.3/busuanzi.pure.mini.js"></script>
<span id="busuanzi_container_site_pv">
  本站总访问量 <span id="busuanzi_value_site_pv"></span> 次
</span>

不加统计你永远不知道你的网站有没有人看，加了之后你会发现——确实没人看 😂 但是随着内容积累，数据会慢慢涨起来的。

最后的话

个人网站是独立开发者最好的名片。不需要等到完美才上线，先搭起来，内容慢慢填充。每写一篇文章、每加一个项目，你的品牌就在成长。

这个网站本身就是我最好的作品——它证明了我能从头到尾搞定一件事。
