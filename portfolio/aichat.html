AIChat — 终端 AI 助手

Python · httpx · SSE · Rich · GitHub ↗

在命令行里和 AI 对话。支持 DeepSeek（国内直连）和 OpenAI 模型，流式输出打字机效果，对话历史可保存可恢复。

核心特性：纯终端运行，不用开浏览器。配置一次 API Key，以后直接在终端里 /ask。

支持的功能

  • 多模型 — DeepSeek (deepseek-chat, deepseek-reasoner) 或 OpenAI (GPT-4o-mini)
  • 流式输出 — 打字机效果，实时看到回复生成
  • 对话历史 — 保存/加载/继续上一次对话
  • Rich UI — 彩色 Markdown 渲染、面板、表格，终端里也能看得很舒服

使用方法

# 安装依赖
pip3 install httpx rich

# 配置 API Key
python3 main.py --config

# 开始对话
python3 main.py

# 继续上一次对话
python3 main.py --resume

内置命令

  • /help — 显示帮助
  • /clear — 清空当前对话
  • /save [名称] — 保存对话
  • /list — 列出已保存的对话
  • /load [名称] — 加载对话
  • /model — 切换模型
