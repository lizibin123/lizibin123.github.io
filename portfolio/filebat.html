FileBat — 文件批量处理工具

Python · Rich · 跨平台 · GitHub ↗

终端里的文件批量处理神器。重命名、复制、移动，支持预览和撤销。Rich 终端界面，操作直观。

核心特性：操作前先预览效果，确认无误再执行。误操作还能一键撤销，告别手滑悲剧。

支持的操作

📝 批量重命名

  • 添加前缀 / 后缀
  • 查找替换（支持正则）
  • 按序号编号（001, 002, ...）
  • 实时预览重命名效果

📁 批量复制 / 移动

  • 按扩展名筛选（如只处理 .jpg / .pdf）
  • 复制或移动到指定目录
  • 保留/重组目录结构

↩️ 撤销

  • 误操作一键回退
  • 支持多次撤销

交互菜单

选择操作:
  [1] 📝 批量重命名
  [2] 📁 批量复制/移动
  [3] ↩️  撤销上一步
  [4] 📂 切换文件夹
  [5] ℹ️  查看状态
  [6] 🚪 退出
