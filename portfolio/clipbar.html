ClipBar — 剪贴板历史管理器

Python · rumps · pyperclip · macOS · GitHub ↗

macOS 菜单栏应用。自动记录剪贴板历史，一键复制回剪贴板。纯离线运行，数据全在本地，不用联网。

核心特性：内存里监控剪贴板变化（~1 秒检测间隔），菜单栏显示最近 20 条，最多保存 100 条历史。

使用界面

启动后在菜单栏显示 📋 图标，点击展开：

📋  ClipBar History
─────────────────────
https://github.com/...
Hello, world!
some config snippet  ↵  {"key": "value"}
...
─────────────────────
🗑  Clear History
✕  Quit

点击任意条目 → 自动复制回剪贴板，粘贴即用。

技术亮点

  • rumps — macOS 菜单栏 App 框架，纯 Python 实现
  • pyperclip — 跨平台剪贴板读写
  • JSON 持久化 — 历史数据存本地，重启不丢失
  • 零联网 — 所有数据留在本机，无隐私风险

如何运行

cd ClipBar
pip3 install -r requirements.txt
python3 main.py
Python 3 rumps pyperclip macOS JSON
