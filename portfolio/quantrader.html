从零搭建的全自动 A 股量化交易系统。覆盖数据获取、因子计算、策略评分、自动交易到风险控制的全链路，无需人工干预。 当前在 openctp 仿真环境稳定运行，策略已迭代至 v2.5。

最新版本 v2.5（2026.06.14）：27 个因子（21 原始 + 3 Alpha101 增益 + 3 FFT 去噪）。回测夏普 3.39，年化 89.29%，回撤 -22.65%。全市场 4000+ 股票动态筛选，月度轮动 Top 10。

因子体系

基础因子（21 个）

均线排列金叉死叉MACD斜率RSI 量价配合资金流向波动率结构趋势强度横截面排名 价量爆发EP 因子业绩增长ATR 突破成交量异常 波动率突变连续涨跌收盘位置高开低走分时趋势 mean_rev_high

Alpha101 增益因子（3 个）

从 Alpha101 因子库精选，与现有因子相关性均 < 0.01：

  • alpha061（量能加速） — 成交量短期 vs 中期均量变化，放量确认趋势
  • alpha060（量价位置） — K 线收盘位置 × 成交量加权，尾盘抢筹/出逃信号
  • alpha049（多周期共振） — 短期收益与长期收益方向一致性，确认/背离信号

FFT 去噪因子（3 个）

  • fft_denoised — 240 天窗口 FFT，保留 15% 低频成分，滤除高频噪音
  • cycle_strength — 主频功率 / 低频总功率比，衡量周期确定性
  • fft_position — 价格偏离去噪线距离，> 3 ATR 触发均值回归

FFT 因子通过 A/B 验证（8/10 股票正向），平均年化 +0.4%，夏普 +0.05。

因子自动挖掘

基于遗传表达式编程的自动化因子生产线：

随机生成 200+→ 粗筛 50→ 精筛 40→ 边际增益 > 0.005→ A/B 验证→ 自动入库

已成功入库 mean_rev_high 因子（IC -0.069，ICIR -2.11），本质为价格均值回归信号，与现有趋势因子互补。周日晚 20:00 自动运行。

交易执行

  • CTP 协议 — C++ shim 封装 + Python ctypes 调用，对接 openctp 仿真交易
  • 三个买入窗口 — 09:25 开盘 / 12:00 午盘 / 14:30 尾盘，动态限价保护
  • 全时段卖出 — 止损 / 止盈 / 移动止损 / 评分卖出，条件触发即时执行
  • 每日四段简报 — 09:30 / 12:00 / 14:30 / 15:00 自动推送 + 自动交易

风控体系（七层）

ATR 止损 1.5× 移动止损 止盈 3.0× 大盘日熔断 累计熔断 CSI300 组合止损 12% 波动率缩仓 跌停自动卖出 连亏冷却 评分暴跌保护 流动性过滤 节假日判断

每一层都是线上运行中修出来的，不是纸上谈兵。2026.06.06 一次性修复了 11 个漏洞（含流动性过滤、评分暴跌保护、节假日判断、CSI300 历史峰值计算、滑点敏感性测试等）。

运维与监控

  • 策略健康检查 — 每周一自动分析因子 IC 衰减、实盘-回测偏差、参数稳定性（变异系数）
  • 滚动窗口验证 — Walk-Forward 分析，检测参数过拟合
  • 滑点敏感性测试 — 不同滑点假设下的策略稳健性评估
  • 资金容量管理 — 单只 ≤ 日均成交额 5%，买入前动态检查
  • 数据新鲜度检查 — 买入前过滤异常陈旧数据

设计原则

仿真是为了找出问题，而不是证明策略有效。 系统经历过数据源中断、CTP 断连、节假日误判、并发写入冲突等线上故障，每一类问题都变成了代码里的一个修复。真正的系统不是在 IDE 里写完就完了，而是在运行中修出来的。

当前运行环境：openctp 仿真交易（≈1000 万模拟资金）· macOS · 全天候自动运行
